# App Store screenshots (iPhone 6.5")

Upload these three, in this order, into the **iPhone 6.5" Display** slot.

| Order | File | What it shows |
|---|---|---|
| 1 | `01-feed-for-you-iphone-6.5-1284x2778.png` | Home feed, TasteWise name, stories, official promo plate |
| 2 | `02-restaurant-posts-iphone-6.5-1284x2778.png` | Restaurant page with food grid, Follow, Reserve |
| 3 | `03-taste-passport-iphone-6.5-1284x2778.png` | Taste Passport ranks and cuisine stamps |

Use the **1284 × 2778** files. The `1242 × 2688` copies are a fallback if App Store Connect asks for that size.

Do not upload empty Create screens. Plate Roulette and Mentions are fine later, not in the first three.

After upload, open **View All Sizes in Media Manager** and let Apple generate the other iPhone sizes.
