## Age rating guidance

When answering Apple’s questionnaire, for a typical social food app:

- Unrestricted web access: **No** (unless you open arbitrary websites)
- Gambling: **No**
- Contests: **No**
- Violence / horror: **None**
- Mature/suggestive themes: **None / Infrequent**
- Profanity: **None / Infrequent** (user-generated text may appear)
- Alcohol / tobacco / drugs references: **Infrequent/Mild** if restaurant content may mention alcohol; otherwise **None**
- Medical/treatment info: **No**
- User-generated content: **Yes** → also enable moderation/reporting if asked
- Messaging / social: **Yes** where asked about social networking features

Expected rating is often **12+** when user-generated content + messaging are enabled.
