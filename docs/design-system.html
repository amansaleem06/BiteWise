Design system

A dining room, not a food court. Maroon, cream, and champagne. Fraunces for the name of the dish; Source Sans 3 for everything you tap. This is the same theme as the Flutter app — published for web, legal, and marketing.

Principles

Clarity

One idea per surface. Type must read at arm’s length. Icons are tools, not decoration.

Deference

The plate is the hero. Chrome recedes — hairline borders, no drop shadows on feed cards, no orange “food app” clichés.

Depth

Motion is 150 / 250 / 400ms. Sheets rise; toasts float. Nothing bounces. Honor reduced motion.

Color

Primary is maroon #4A0E0E. In dark mode, interactive color flips to champagne #B8956A — matching AppTheme.

12-column grid

Max 1120px. Gutter 24px. Margins 16 / 24 / 48. Columns collapse to 12-span on small screens; 4 / 6 / 8 from 768px.

In-app lists cap at 720px (AppBreakpoints.contentMax). Marketing is wider; product UI is not.

8px spacing

Base unit 8. Half-step 4 only for icon optical alignment. Prefer 8, 16, 24, 32, 48, 64, 80, 96, 128.

Radius, elevation, motion

Inputs 16 · cards 28 · buttons/chips pill. Elevation is hairline + rare soft shadow. Duration 150 / 250 / 400. Easing cubic-bezier(0.2, 0, 0, 1) for emphasized.

Do’s and don’ts

Do set dishes in Fraunces and UI in Source Sans 3.
Don’t use Segoe, Inter, or orange links on this brand.
Do let photographs (or plate media) carry emotion.
Don’t drop heavy shadows on feed cards.
Do use champagne for stamps, stars, and focus.
Don’t set body copy in champagne on cream.
Do keep one primary button per screen.
Don’t use the brand gradient on every CTA — only the seal and the closing band.

Developer guide

  1. Read DESIGN.md before adding a color or type size.
  2. Web: use CSS variables, never hex in components.
  3. Flutter: AppColors, AppSpacing, AppTypography, AppRadius. No new palette without a token.
  4. If you add a token, update tokens.json, CSS, and Dart in the same change.
  5. Legal and marketing share this CSS so App Store URLs stay on-brand.
