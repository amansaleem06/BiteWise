# BiteWise

Discover. Taste. Share. — a food-focused social app built with Flutter + Firebase.

## Run locally (Android / Windows)

```bash
flutter pub get
flutter run
```

On Windows, use the Android emulator or `dev_setup/RUN_BITEWISE.bat`.
